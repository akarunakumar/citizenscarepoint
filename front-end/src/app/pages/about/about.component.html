About

Why CitizenCarePoint exists

Citizens end up bouncing between a dozen apps and offices for routine tasks — payroll paperwork, tax calculations, booking home services. CitizenCarePoint's vision is to bring these everyday needs together.

"One platform for everyday citizen and personal services."

This is currently a learning project. As of Phase 4, the frontend is being migrated from plain HTML/CSS/JS to Angular, one route at a time.

Roadmap

How this project is planned to evolve, phase by phase.

  • Phase 1 HTML + CSS + JavaScript static frontend.
  • Phase 2 Client-side functionality with localStorage.
  • Phase 3 Backend APIs and database (Java + Spring Boot).
  • Phase 4 Migrate the frontend to Angular (current).
  • Phase 5 Authentication, authorization and user accounts.
  • Phase 6 Containerize the application with Docker.
  • Phase 7 CI/CD with GitHub Actions and DevOps deployment.
